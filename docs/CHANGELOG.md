# Changelog

## 0.2.0 — successor development

Expanded the visual library to 56 presets and added four procedural shader
families, reusable JSON preset configuration, palette editing, preset saving
and sharing, custom motion/deformation/glow tuning, idle control hiding,
fade transitions, frame-rate limits, real waveform display, overlapping stereo
analysis, attack/decay smoothing, transient detection, queue editing and track
shuffle, and local/MPRIS metadata. Started the native Rust audio workspace.

## 0.1.0 — first desktop baseline

24 original presets, four palette modes, GPU bloom, system-audio and microphone
selection, local playback, gallery/shuffle, fullscreen, persistent preferences,
a user-local installer and GNOME launcher. Validated on RTX 4090 with PipeWire.
